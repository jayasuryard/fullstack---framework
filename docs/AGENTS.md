# AI Agents

## Agent System

RyoFramework defines specialized AI agents for different domains.

### Architect Agent
- Responsible for system architecture decisions
- Reviews architecture proposals
- Ensures scalability and maintainability

### Backend Agent
- Implements backend endpoints
- Follows layered architecture
- Ensures API consistency

### Frontend Agent
- Builds React components
- Ensures UI consistency
- Implements responsive design

### Database Agent
- Designs Prisma schemas
- Optimizes queries
- Manages migrations

### Security Agent
- Reviews code for vulnerabilities
- Ensures OWASP compliance
- Validates authentication/authorization

### QA Agent
- Writes tests
- Ensures code quality
- Validates edge cases

### Documentation Agent
- Maintains documentation
- Updates API documentation
- Ensures docs stay synchronized

### DevOps Agent
- Maintains Docker configuration
- Manages CI/CD pipelines
- Ensures deployment readiness

### Review Agent
- Reviews all generated code
- Ensures adherence to standards
- Provides actionable feedback
